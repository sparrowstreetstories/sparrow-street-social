# Sparrow Street · social robot

Posts Sparrow Street's own, already-approved pictures and clips to its own Instagram, Facebook and Pinterest accounts on a schedule, and hides spam or unkind comments (it never replies). Plan: `business/SOCIAL_AUTOMATION_PLAN.md` in the Sparrow Street project.

- `docs/`: the public web page (GitHub Pages): the privacy policy, the Pinterest callback page, and `media/` (the post images and clips Instagram fetches).
- Keys live only in GitHub's secret store (Settings → Secrets and variables → Actions), never in this repository.
